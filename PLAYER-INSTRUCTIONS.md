# Install StickyBusinessAccess

Download **StickyBusinessAccess-0.8.2-setup2-player.zip** from the **Assets** section of the [StickyBusinessAccess Releases page](https://github.com/MiloSummers/StickyBusinessAccess/releases/latest).

**Do not select “Source code (zip)” or “Source code (tar.gz)”. Do not select an archive labelled DEVELOPER-source or prism-source. Those downloads cannot install the mod.** GitHub automatically provides the two “Source code” downloads for release tags; this project cannot remove them as ordinary uploaded assets.

1. Open the Releases page. With your screen reader, locate the Assets section and the link named **StickyBusinessAccess-0.8.2-setup2-player.zip**. Expand Assets if needed.
2. Download that exact ZIP. In File Explorer, select it and use **Extract All**. Open the extracted folder; do not run Setup from inside the ZIP.
3. Close Sticky Business. Run **Setup.bat** from the extracted folder and follow its spoken/text prompts. Keep the **support** folder beside Setup.bat; no manual copying or developer tools are needed.
4. Start your supported screen reader, then launch Sticky Business through Steam. The first launch needs internet access and may take several minutes.

Run the game once and close it before installation if you have not already done so. You must own and install Sticky Business separately.

For updates, extract the new player ZIP and run Setup.bat. To remove the mod, close the game and run Uninstall.bat from the extracted player folder. Keep that folder for updates and removal.

If Setup says you may have downloaded source code, return to Assets and choose the exact player ZIP above. If it reports a missing file or checksum mismatch, download the player ZIP again and extract it into a new folder. The error includes the affected path. Payload validation happens before any game files are changed.

This installer revision improves download guidance and diagnostics. The existing v0.8.2 player ZIP was complete; this revision does not fix an omitted payload in that package. The accessibility mod remains version 0.8.2, and its full runtime, dependencies, licences and corresponding-source materials remain included.
