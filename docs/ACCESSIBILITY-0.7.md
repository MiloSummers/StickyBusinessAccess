# Accessibility update 0.7 — 2 October 2026

## Investigation and changes

1. Information access: F5 provides a spoken view with Shop status, Current order, Printed sticker inventory and Purchased goodies. It preserves the native scene and previous navigation focus. Sections refresh from the loaded game; no major sidebar redesign was needed. Ordinary typing and NVDA modifiers retain priority.
2. End of day: both mod-generated text-section and control-position suffixes are suppressed on SleepScreen. Actual result text is retained.
3. Inventory: PrinterInventoryStickerElement has images/text and no native Selectable. Read-only keyboard targets now expose those rows; scroll clipping does not remove them, focus reveals rows, and names/available/ordered counts use native data. The separate F5 stock section includes all non-deleted designs, including zero stock. Native creator categories and packing tabs are retained.
4. Hearts: Game.Money and Game.Fame are the actual balances. B reads both, including when the bottom bar is not visible.
5. Paper/filling: CustomerOrder has sticker IDs, status, message, payment and fame fields; it has no paper/filling requirement fields. FillingController stores player packing choices. Order speech now names the selected PaperData/FillingData, with customer messages retained. This does not infer new requirements from generic headings or alter fulfillment validation.
6. Goodies: Game.Goodies stores quantities separately from printed stock. Native GoodieElementSpawner.CheckEnabled disables its controller button in mouse mode; therefore a separate keyboard proxy is used, without overriding that input-mode decision. It invokes the real OnClick path, which spends one goodie, creates its copy and applies native box/bonus callbacks. Copies have selectable names, stock/use feedback, selected state, movement and native deletion/stock restoration. F9 also reaches a placed goodie when present. Only the selected packing category's spawners enter navigation.
7. Dialogue detection: the old sticker handlers interpreted any failed mouse raycast as a dialogue. Controller proxies, clipping and non-mouse targets can fail that test. Activation now checks current screen ownership, visible state and actual popup/tutorial resolution for these targets. Real blocking panels retain focus ownership, and failed activation identifies their title and text. This is not a blanket removal of modal checks; normal buttons retain hit tests.
8. Order switching: LetterManager.UpdateOrderView explicitly disables next/previous buttons when elementsInLetter is nonempty. ShowNextOrder/ShowPreviousOrder require packingEnabled and switchingOrdersEnabled. These restrictions are retained, with a reason spoken when unavailable. Switching an empty box uses native controls and the existing settled customer announcement.
9. External publisher button: the serialized more-games callback calls StoreIntegration.OpenMoreFromSpellgarden, which unconditionally requests SteamFriends.ActivateGameOverlayToWebPage. Its exact destination is the Steam Spellgarden publisher page. Keyboard activation opens that destination through Application.OpenURL, providing a browser route when the Steam overlay is inaccessible. The original visual callback is unchanged.
10. Day length: GameManager.Update does not decrement a running day clock. Game.TryUseMinutes consumes action costs and emits TimeChanged; Limitless already skips deductions. GetGameSpeed selects Normal, Relaxed or Limitless preset costs. The optional setting returns adjusted copies of those costs, with Normal unchanged by default, 1.25/1.5/2x extensions or zero-cost Unlimited. Shared preset assets, saved difficulty, animations, manual Sleep, deadlines and other gameplay logic are not rewritten. Whole-minute rounding makes finite multipliers approximate. No game-level leaderboard usage was identified in the inspected game methods; bundled platform libraries contain generic leaderboard APIs, which does not establish their use by this game.

## Verification and limitations

The release builds with zero warnings/errors. All 32 automated checks pass: the previous 24 catalogue/navigation/text-editing checks plus 8 action-cost checks.

Isolated game integration invokes real controls and mod keyboard handlers with disposable copies of earlier fixture saves. Verified live coin/heart speech; F5 sections and return; native Next/Previous customer switching; disabled switching explanation while a sticker is packed; sticker placement/deletion; end-of-day content without position suffixes; navigable inventory row with available/ordered quantities; purchased goodie discovery, placement, selected/unselected state, movement and deletion restoring its quantity; all finite/Unlimited action-cost values and restoration to native costs; the accessible Settings day-length control; printing adding 12 stock (9 to 21); Normal consuming native minutes, optional Unlimited consuming zero, and native Limitless preserving its zero deductions. The fixture's Relaxed base creation/print/packing/posting costs were 60/10/10/30; 2x produced 30/5/5/15, and Unlimited produced zeroes.

Test-harness commands with trailing newlines, mismatched display labels and an overly broad prefix produced fixture lookup errors during exploratory checks; corrected commands were rerun. These are distinct from mod access errors. Private fixture code, save redirection, Steam branch metadata query fixture and input injection are excluded from the release. The metadata fixture does not modify ownership, authentication or DLC.

Physical keyboard timing, audible NVDA output, browser/Steam page rendering, every DLC goodie, every unlocked category, large inventories and every tutorial branch still need live testing. No audible-NVDA or visual-layout certification is claimed. Existing slider adjustment and text-editing code was preserved; existing tests passed. This report does not claim all prior functionality has been exhaustively retested.

Use Setup.bat with the game closed. For an installed mod it replaces the owned plugin and retains rollback, without replacing original game files or saves. Normal timing is the default; choose additional day length explicitly in Settings > Accessibility controls.
